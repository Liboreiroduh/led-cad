# PROJETO: LED STRUCTURE CAD
## Mini-CAD paramétrico para estruturas de painéis de LED

Você atuará como ARQUITETO DE SOFTWARE SÊNIOR + DESENVOLVEDOR PYTHON + ESPECIALISTA EM GEOMETRIA/CAD PARAMÉTRICO.

Este projeto NÃO é um site comum.
Este projeto NÃO é um gerador de imagens por IA.
Este projeto NÃO é um AutoCAD completo.
Este projeto NÃO deve ser reconstruído em Node.js, React, Next.js, Vite ou frameworks semelhantes.

A aplicação deverá ser PYTHON-FIRST.

Antes de escrever código, leia completamente esta especificação.

============================================================
2. OBJETIVO DO PRODUTO
============================================================

Criar uma espécie de CAD simplificado específico para estruturas
metálicas utilizadas na instalação de painéis de LED da LED COLLOR.

O objetivo é permitir que um usuário parta de um PRESET estrutural
e consiga rapidamente produzir um esboço técnico compreensível.

Exemplo:

Painel:
4000 x 2000 mm

Aplicação:
Outdoor / DOOH

Instalação:
1 poste central

Altura inferior do painel:
3000 mm do solo

Profundidade:
800 mm

O sistema monta automaticamente uma estrutura inicial.

Depois disso o usuário poderá editar essa estrutura.

A função principal do programa é:

PRESET
   ↓
MODELO 3D
   ↓
EDIÇÃO
   ↓
VISTAS ORTOGRÁFICAS
   ↓
COTAS
   ↓
PRANCHA TÉCNICA
   ↓
PDF

============================================================
9. SISTEMA DE COORDENADAS
============================================================

Defina explicitamente um sistema único.

Sugestão:

X = horizontal / largura
Y = profundidade
Z = altura

Origem:

X = centro da estrutura
Y = centro/profundidade de referência
Z = solo

Exemplo:

poste central:

X = 0
Y = 0
Z = 0

altura inferior do painel:

Z = 3000

Essa convenção deverá ser utilizada por TODO o projeto.

============================================================
10. MODELO CANÔNICO DO PROJETO
============================================================

Toda a aplicação deverá operar sobre um modelo estruturado.

Exemplo conceitual:

{
  "project": {
    "name": "Painel 4x2 Outdoor",
    "units": "mm"
  },

  "panel": {
    "width": 4000,
    "height": 2000,
    "depth": 800
  },

  "installation": {
    "type": "post",
    "ground_clearance": 3000,
    "environment": "outdoor"
  },

  "elements": []
}

Cada elemento:

{
  "id": "V01",
  "type": "beam",
  "profile": "40x40x2",
  "start": [x, y, z],
  "end": [x, y, z]
}

ou uma estrutura equivalente bem projetada.

A geometria deverá sempre poder ser reconstruída a partir deste modelo.

O JSON do projeto é mais importante do que o mesh renderizado.

23. IA
============================================================

A IA NÃO deve desenhar a estrutura diretamente.

A IA NÃO deve gerar código para cada projeto.

A IA NÃO deve modificar Python durante a operação normal.

A IA serve para interpretar intenção do usuário.

Exemplo:

Usuário:

"adicione outro poste 1200 mm para a direita"

IA:

{
    "operation": "add_post",
    "x": 1200,
    "y": 0,
    "height": 3000
}

Outro exemplo:

"mova o poste central 400 mm para esquerda"

IA:

{
    "operation": "move_element",
    "element_id": "POSTE-01",
    "delta_x": -400
}

Então o CORE PYTHON executa a operação.

A IA nunca deve escrever geometria arbitrária diretamente.
