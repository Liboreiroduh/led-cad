# LedCollor Studio — regras do orquestrador

Leia primeiro `zai/ORCHESTRATOR_PROMPT.md`, `zai/ROADMAP.md`, `zai/PROJECT_CONTEXT.md` e a task marcada como ativa em `zai/tasks/`.

Execute uma task por vez. Não comece outra task enquanto a atual não tiver sido validada no navegador e seu status não tiver sido atualizado.

Este é um protótipo: priorize fluxo utilizável e visualização publicada. Não crie uma grande suíte de testes; valide apenas o comportamento essencial e a build. Não implemente login, billing, colaboração, cálculos estruturais ou recursos fora da task ativa.

Quando concluir uma task, atualize o arquivo da task com:

- status `concluída`;
- arquivos criados ou alterados;
- URL local ou pública validada;
- limitações que afetem a revisão;
- próxima task recomendada.

Antes de alterar a geometria, mantenha dimensões centralizadas e diferencie dimensões nominais de espessuras representativas. Nunca declare dimensionamento ou segurança estrutural.
